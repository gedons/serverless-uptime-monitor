# Serverless Uptime Monitor

A serverless uptime monitoring platform built with AWS Lambda, API Gateway, DynamoDB, EventBridge, SNS, and Nuxt.

## Status

🚧 Under Development

## Architecture

The application uses AWS serverless services to monitor websites and APIs, record uptime metrics, detect incidents, and notify users when monitored services go down or recover.

## Planned Features

- Monitor websites and APIs
- Scheduled health checks
- Response time monitoring
- HTTP status monitoring
- Uptime calculations
- Incident tracking
- Email notifications
- Historical monitoring data
- Dashboard
- AWS-native observability
